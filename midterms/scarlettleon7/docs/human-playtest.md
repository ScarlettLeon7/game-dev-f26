# Human Playtest — SuperTux Classic

**Date:** November 8, 2026  
**Playtester:** A friend, unfamiliar with my modifications  
**Game:** SuperTux Classic, first level  
**Method:** The participant played the game without gameplay coaching.

## Observations

The participant had a generally normal gameplay experience and was able to explore the first level using the standard controls.

One usability issue emerged: it took the participant some time to discover that pressing **Shift** was necessary to throw a fireball, and that the up arrow key does not make Tux jump, the **space** key does.

## Feedback and Interpretation

The fireball mechanic was not immediately discoverable. This suggests that the game could benefit from clearer control instructions, such as a controls screen or an on-screen hint.

## Changes and Limitations

I decided to preserve the original game's controls and level design because the main focus of my midterm was implementing an autonomous AI player rather than redesigning the human interface.

I documented the control-discoverability issue as a limitation instead of changing gameplay immediately before submission.

This playtest supports basic human playability, but it does not establish that every level or mechanic is free of usability issues.
